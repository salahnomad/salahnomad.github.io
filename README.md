# The old workshop — salahnomad.github.io

> *"One does not leave a house. One leaves a lamp burning inside."*

This repository is the former workshop of salahnomad.com, where I wrote my first articles between 2025 and the summer of 2026, hosted on GitHub Pages. It remains public on purpose — not as a dusty museum, but as an open workshop where anyone can still see the shavings on the floor, the tools on the workbench, the traces of the work.

The blog has moved elsewhere. This is not a rejection of open source; it is a craftsman's choice: keep the workshop open for those who want to learn, but protect the work in progress.

**→ Current blog**: [salahnomad.com](https://salahnomad.com)

---

## Why this workshop stays open

Four reasons, as plain as the four walls of a house.

**A debt to those who linked here.** A few developers, a few readers, a few passing bots pointed to specific files in this repository. Breaking those links would be a small dishonesty. I prefer to leave the door open.

**The trace of the gesture.** 3,899 commits. Two years of work, of mistakes, of stepping back, of nights spent refining a single SCSS rule. Erasing this would erase part of the journey. The code stays as a sketchbook left open on a table.

**Learning by example.** If you are starting out with Hugo, if you are looking for how to structure a custom theme, if you want to see how a multilingual blog handles data files — take, dig through, be inspired. That is what it is here for.

**Coherence with what I write about.** I write about rootedness, about what we keep and what we leave behind, about the memory of places. It would be strange to advocate fidelity to traces and then erase my own.

## What you will not find here

- No active deployment. GitHub Pages has been disabled.
- No updates. This code is frozen in its summer 2026 state.

What you will find: a snapshot. A still frame.

## One last word

I have sometimes been asked why I keep this repository visible when the source code of the current blog is private. The answer fits in a line from Gaston Bachelard that I like to return to: *"The house, like the nest, like the cave, has a value of intimacy that defends against the universe."*

The current blog is my house. This repository is the cave I set out from. Both deserve to exist.
